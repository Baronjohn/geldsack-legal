# Geldsack: rechtliche Seiten

Öffentliche Seiten für die App-Stores (Datenschutz, Impressum, Haftungsausschluss), veröffentlicht über GitHub Pages.

Die Dateien werden generiert, nicht von Hand bearbeitet. Die Texte stehen im App-Repo in `src/i18n/de.json` (`legal.*`); `npm run legal:pages` schreibt sie hierher.
